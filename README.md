# 🖱️ ESP32-C3 Air Mouse

A wireless **gesture-controlled Air Mouse** built using an **ESP32-C3 Mini** and **MPU6050**. It uses motion sensing and Bluetooth HID to control a computer without a traditional mouse.

## ✨ Features

- 🎯 Motion-based cursor control
- 🖱️ Left & right mouse click
- 🔄 Potentiometer-based scrolling
- 📊 PPT slide up/down control
- 📡 Bluetooth HID connectivity
- 🔋 Li-Po rechargeable battery
- ⚡ TP4056 charging module
- 🖨️ Custom 3D-printed enclosure

## 🔧 Components

- ESP32-C3 Mini
- MPU6050
- Push Buttons
- Potentiometer
- TP4056 Charging Module
- Li-Po Battery
- 3D-Printed Enclosure

## 🔌 MPU6050 Connection

| MPU6050 | ESP32-C3 |
|---|---|
| VCC | 3.3V |
| GND | GND |
| SDA | GPIO 1 |
| SCL | GPIO 2 |

**I²C Address:** `0x68`

## 🛠️ Software

- Arduino IDE
- Embedded C/C++
- I²C Communication
- Bluetooth HID

## 📌 Project

This project combines **embedded systems, wireless communication, IMU sensing, Bluetooth HID, and 3D printing** to create a portable computer input device.
